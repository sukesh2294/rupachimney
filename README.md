## ✨ About The Project

**Rupa Chimney** is a premium brick manufacturing company established in **2000**, located in **Sikandra, Jamui, Bihar**.

This web application provides:

- 🌐 **Modern Business Presence** – Showcase products & services  
- 🤝 **Customer Engagement** – Enquiry & contact system  
- 🔐 **Admin Management** – Secure content management  
- 📱 **Responsive Design** – Optimized for all devices
